## GESTION DES IMAGES

Les images du site doivent être considérées comme de véritables assets du projet.

IMPORTANT :

Tu ne dois pas inventer de nouvelles images différentes du style défini dans la direction artistique.

Pour chaque asset :

1. Prévoir son emplacement exact dans l'interface.
2. Utiliser Next/Image lorsque pertinent.
3. Définir correctement les dimensions.
4. Utiliser un alt text descriptif.
5. Prévoir un affichage responsive.
6. Éviter les Layout Shifts.
7. Utiliser lazy loading pour les images qui ne sont pas immédiatement visibles.
8. Ne jamais remplacer une image par une autre provenant d'Internet sans mon autorisation.

Si les fichiers image sont déjà présents dans le projet, inspecte-les et utilise-les directement.

Si les fichiers ne sont pas encore présents, utilise temporairement un placeholder local clairement identifié, mais construis le code de façon à ce que le remplacement par les fichiers finaux ne nécessite aucune modification de l'architecture.

NE PAS utiliser :

* Unsplash
* images Google
* images externes aléatoires
* URLs d'images qui peuvent disparaître
* images provenant de sources différentes ayant des styles incohérents.

L'objectif est que toutes les images finales appartiennent à la même identité visuelle HALLOWYS.

IMPORTANT :

Ne génère aucun texte dans les images.

Les titres, prix, promotions et CTA doivent toujours être du HTML/CSS au-dessus de l'image.

Les images doivent uniquement servir à créer l'univers visuel et présenter les produits.
